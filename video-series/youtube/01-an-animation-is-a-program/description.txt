A screen can't show motion, only still frames. So who draws all the in-between shapes when a square becomes a circle? In Manim, you don't: you describe the change, and the computer draws every frame.

This episode opens ManimOnline in the browser, tours the editor, reads a first scene line by line (Scene, construct, objects, self.play, self.wait), makes the first edits, and reads an error message without fear.
