Deep dive 3, and the series finale: how a link or a QR code can carry a program with no server of its own. Code inside the link, compressed with back-references (the Lempel-Ziv idea); where links run out; cryptographic hashes and the avalanche effect.

Then the anatomy of a HashBin content address, why content-addressed links suit printed QR codes and what can still go wrong, and how the editor keeps itself available offline.
